# Derm7pt Dataset Card

## Audit status

- Audit version: Data Audit v0.1
- Local sample unit: one metadata case
- Local metadata rows: 1,011
- Local extracted images: 2,013 unique image files
- Evidence source: local release metadata, image inventory, split files, and
  `README.txt`; aggregate results are generated by
  `scripts/audit_datasets.py`.

Original images are local research data and are not distributed by this
repository.

## Modality

Each metadata case contains:

- one clinical photograph reference; and
- one dermoscopy image reference.

These support Paper 1 Domain B (Derm7pt Clinical) and Domain A (Derm7pt
Dermoscopy), respectively. Across both reference columns there are 2,022
references to 2,013 unique files. The nine-reference excess represents
duplicate references, not missing images.

non-melanoma, not malignant versus benign.

## Concept annotations

All 1,011 metadata rows have a value for each of the seven clinical concepts:

- pigment network
- streaks
- pigmentation
- regression structures
- dots and globules
- blue-whitish veil
- vascular structures

The values are categorical annotations. Data Audit v0.1 reports each raw
category without collapsing or reinterpreting it.

## Metadata

The audited local metadata has 19 columns:

- identifiers and diagnosis: `case_num`, `case_id`, `diagnosis`;
- score and concepts: `seven_point_score` and the seven concept columns;
- clinical context: `level_of_diagnostic_difficulty`, `elevation`,
  `location`, `sex`, `management`;
- image references: `clinic`, `derm`; and
- free-text/supporting field: `notes`.

`case_id` and `notes` have substantial missingness. They are not required for
Paper 1 cohort membership or the binary target.

## Split

The release supplies zero-based official indexes:

- train: 413 cases
- validation: 203 cases
- test: 395 cases

Data Audit v0.1 verifies that indexes are unique within each split, pairwise
disjoint, in range, and together cover all 1,011 metadata rows exactly. The
audit does not generate or modify these splits.

## Known limitations

- The dataset is modest in size and has diagnosis imbalance.
- Some image paths are referenced more than once across clinical and
  dermoscopy columns; evaluation code must not treat references as independent
  cases.
- Clinical and dermoscopy images are paired by case, so modality comparisons
  must preserve case grouping.
- `case_id` and `notes` are mostly missing in the local metadata.
- The audit validates file/reference consistency, not image quality,
  acquisition-device metadata, label provenance, or inter-rater reliability.
- Paper 1 must not infer patient-level independence because a verified
  patient identifier is not available in the audited metadata.

## Paper 1 usage

- Domain A: Derm7pt dermoscopy (`derm`)
- Domain B: Derm7pt clinical photography (`clinic`)
- Task: melanoma (`target=1`) versus non-melanoma (`target=0`)
- Planned comparisons: A→A, A→B, B→B, with A→B representing modality shift
  within the same dataset.
- Primary metrics: AUROC, AUPRC, melanoma sensitivity, and specificity.
- Secondary metrics: F1, balanced accuracy, and calibration/ECE.

Ordinary accuracy is not a primary Paper 1 conclusion.
