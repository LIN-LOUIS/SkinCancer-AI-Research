# PAD-UFES-20 Dataset Card

## Audit status

- Audit version: Data Audit v0.1
- Local sample unit: one metadata image row
- Local metadata rows: 2,298
- Local extracted images: 2,298 PNG files
- Local unique patients: 1,373
- Local unique lesions: 1,641
- Evidence source: local metadata and extracted image inventory; aggregate
  results are generated by `scripts/audit_datasets.py`.

Original images and row-level clinical metadata are local research data and
are not distributed by this repository.

## Modality

The audited copy contains clinical skin-lesion photographs. Paper 1 uses this
dataset as Domain C (PAD-UFES-20 Clinical).

## Diagnosis

The local metadata contains six raw labels:

- `ACK`
- `BCC`
- `MEL`
- `NEV`
- `SCC`
- `SEK`

Paper 1 maps only `MEL` to melanoma (`target=1`). `ACK`, `BCC`, `NEV`, `SCC`,
and `SEK` map to non-melanoma (`target=0`). In particular, BCC and SCC are
malignant but remain non-melanoma; the task is not malignant versus benign.

The authoritative mapping is
`datasets/mappings/melanoma_binary_v0.1.csv`.

## Concept annotations

PAD-UFES-20 does not contain the seven Derm7pt clinical-concept ground-truth
columns. It contains clinical attributes such as itch, growth, pain, change,
bleeding, and elevation, but Data Audit v0.1 does not reinterpret these as
Derm7pt concept annotations.

## Metadata

The audited local metadata has 26 columns:

- grouping and image identity: `patient_id`, `lesion_id`, `img_id`;
- demographics/context: `age`, `gender`, `fitspatrick`, `region`, parental
  background fields;
- history/environment: smoking, alcohol, pesticide exposure, cancer history,
  water, and sewage fields;
- lesion measurements and symptoms: two diameters, itch, growth, pain,
  change, bleeding, and elevation;
- diagnosis: `diagnostic`; and
- verification context: `biopsed`.

Identifiers are used only for aggregate multiplicity checks and future
group-aware splitting. They are never exported in audit artifacts.

## Split

No official train/validation/test split is established by Data Audit v0.1.
Future Paper 1 splits must be patient-aware and should also preserve lesion
grouping. Split definitions must be versioned separately before baseline
training.

## Known limitations

- Melanoma prevalence is approximately 2.26%, creating severe class
  imbalance; ordinary accuracy is unsuitable as a primary metric.
- Multiple images may belong to the same patient or lesion. Image-level random
  splitting would risk leakage.
- Eleven clinical/context fields share a large identical missing-row set in
  the audited copy. Parental-background fields contain additional missingness.
- Eight fields use explicit `UNK` values in the audited copy. These include
  `background_father` (95, in addition to 818 blanks), `background_mother`
  (84, in addition to 822 blanks), `grew` (402), `changed` (396), `hurt`
  (10), `itch` (6), `bleed` (6), and `elevation` (2). Data Audit v0.1 reports
  blank and encoded-unknown counts separately and uses their union for total
  missingness.
- The shared missingness is associated descriptively with unbiopsied rows in
  the audited copy. This does not prove a causal missingness mechanism or
  justify treating values as missing at random.
- Complete-case filtering could change class and acquisition composition and
  must not be applied without a frozen protocol.
- Data Audit v0.1 verifies metadata/image matching, not image quality,
  acquisition-device shift, diagnostic adjudication, or demographic fairness.

## Paper 1 usage

- Domain C: PAD-UFES-20 clinical photography
- Task: melanoma (`MEL`, target 1) versus non-melanoma (target 0)
- Planned comparisons: A→C and B→C
- A→C represents modality plus dataset/acquisition shift.
- B→C represents clinical-image dataset/acquisition shift.
- Primary metrics: AUROC, AUPRC, melanoma sensitivity, and specificity.
- Secondary metrics: F1, balanced accuracy, and calibration/ECE.

The baseline protocol must define patient-aware splits, threshold selection,
class-imbalance handling, confidence intervals, and calibration evaluation
before training begins.
